# 大万状态监控屏主题

把用户的视觉偏好转成可直接导入的 `.wmtheme.json`。读取 [主题格式](references/theme-format.md) 和 [自绘图标示例](assets/starship-console.wmtheme.json)。为 480×480 实屏设计，优先保证读数、文字和操作按钮清晰。已有主题按用户指定的范围修改。

**新主题只有一个名字或风格时，可以直接开始。** 从题材选取能辨认的形状，为 CPU、GPU、内存、系统盘绘制四个有区别的 8×8 像素图标，同时设计配色和卡片层次。用 24×24 实显尺寸判断轮廓，避免用原来的蘑菇、花、绿管和金币给无关题材换色。有明确图标要求时沿用用户选择。自绘图标示例只用于理解格式。

用户未指定布局时，运行 `python scripts/dawan_theme.py --suggest-layout`，从四宫格、四条横排和主卡加三条横排中选一种。已经知道上一套布局时，可加 `--exclude-layout <上一套>`。只能处理附件时按题材自行选择一种布局。有明确布局要求时保持该布局。图标和布局在生成时确定。

可执行 Python 3 时，运行 `python scripts/dawan_theme.py <主题文件>`，校验通过后交付文件。仅能处理附件时，按主题格式逐项核对，交付 JSON 并说明脚本校验待由上位机导入时完成。主题只描述外观，实时数据由上位机提供。

交付新主题使用格式 2，需 2.0.2 或更新的上位机和设备应用。用户明确使用旧版本时，使用格式 1 的布局和图标。交付时给出主题文件，并说明在上位机点「上传主题」、在大万预览后点「安装」。
